# Frontend Rules (PART 16, 17)

⚠️ **These rules are NON-NEGOTIABLE. Violations are bugs.** ⚠️

## CRITICAL - NEVER DO

- NEVER use JavaScript frameworks (React, Vue, Angular, etc.)
- NEVER use inline CSS
- NEVER use JavaScript alerts
- NEVER skip mobile-first design
- NEVER skip CSRF protection on forms

## CRITICAL - ALWAYS DO

- ALWAYS use mobile-first responsive design
- ALWAYS support dark/light/auto themes
- ALWAYS use vanilla JavaScript (no frameworks)
- ALWAYS use CSS-only animations where possible
- ALWAYS embed templates with Go embed
- ALWAYS have admin panel with full settings UI
- ALWAYS use CSRF tokens on all state-changing forms
- ALWAYS provide professional UI/UX

## Key Rules

| Rule | Description |
|------|-------------|
| **Mobile-first** | Start mobile, expand to desktop |
| **Themes** | Dark, light, auto (system preference) |
| **No frameworks** | Vanilla JS, CSS-only where possible |
| **Admin panel** | All settings editable, grouped logically |
| **Tooltips/help** | Every setting has description |
| **Validation** | Real-time with clear error messages |
| **CSRF** | All forms must have CSRF tokens |
| **PWA** | Installable, offline-capable |
